# 隐私说明

王二审计抽凭采用本地优先架构，但“本地优先”不等于任何情况下数据都不会离开设备。

## 本地处理

以下环节由 Windows 便携引擎在本地执行：

- 读取 PDF 和图片；
- 页面转换和 PaddleOCR；
- OCR 词级坐标记录；
- 字段与证据坐标匹配；
- Excel、链接和高亮预览生成；
- 任务文件保存和恢复。

项目本身不包含遥测、用户账户、远程服务器或内置云 OCR。

## Agent 处理

本地引擎会生成包含 OCR 文本的 `agent-input.json` 和 `agent-prompt.txt`。Agent 需要读取这些文字并返回结构化字段。

- 使用完全本地运行的 Agent 或模型时，OCR 文本可留在本机；
- 使用联网 Agent 时，OCR 文本可能发送给该 Agent 的服务提供商；
- 具体保存、训练和跨境处理规则由用户选择的 Agent、账号和组织配置决定。

用户应在处理客户资料前自行确认授权和单位制度。无法确认时，不应使用联网 Agent 处理敏感 OCR 文本。

## 公开反馈

不要在公开 Issue、Discussion、截图或日志中提交：

- 客户名称、人员姓名和联系方式；
- 银行账号、发票号码、合同信息和金额明细；
- 原始凭证、OCR 全文和工作底稿；
- 本地绝对路径、用户名或组织内部地址；
- API Key、Token、密码或配置文件。

请使用虚构数据或不可逆脱敏的最小复现材料。
