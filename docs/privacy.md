# 隐私说明

飞段抽凭工具采用本地处理优先的方式，但这不表示任何情况下资料都不会离开设备。

## 本地处理

Windows 包中的本地 Engine 负责读取 PDF 和图片、页面处理、OCR、证据坐标匹配、Excel 与高亮预览生成，以及本地任务文件保存。任务数据默认保存在用户电脑，具体位置以安装包说明为准。

## Agent 与模型处理

字段判断需要 Agent 读取 OCR 候选文字。使用联网的 Agent 或模型时，这些文字可能发送给相应服务提供商；具体保存、训练、跨境传输与访问规则取决于用户选择的产品、账号和组织配置。原始 PDF 不会仅因这一流程自动上传，但用户仍应在处理敏感资料前确认实际 Agent 客户端和单位制度。

如需完全在本地处理，用户应选择本地模型，并自行确认所用 Agent 客户端没有额外联网行为。本说明不替代用户的安全、合规或审计判断。

## 公开反馈

请不要在公开 Issue、Discussion、截图或日志中提交客户名称、个人信息、账号或金额明细、原始凭证、OCR 全文、工作底稿、本地路径、访问令牌、密码或配置文件。请仅使用虚构或不可逆脱敏的最小复现材料。
